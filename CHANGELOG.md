# Changelog

Все заметные изменения HH-Auto-Response в хронологии

## 1.0.2-beta — 2026-10-04

Главное: выдача по резюме снова проходится целиком, а нейросеть в анкетах больше не бросает вакансию
со словами «в резюме нет такого опыта».

### Исправлено

- **Выдача «подходящие к резюме» обрывалась после первой страницы без объяснений.** hh перестал показывать
  в этой выдаче кнопку «дальше», и программа решала, что страниц больше нет. Теперь следующая страница
  определяется по номерам страниц и по «Найдено N вакансий» в шапке выдачи. Проверено на живой выдаче
  на 426 вакансий: пройдены все 9 страниц.
- **Нейросеть отказывалась от анкеты, если в резюме не было нужного опыта** (например, «Опишите опыт
  с Apache Airflow»), и вакансия пропускалась. Теперь отсутствие опыта — не причина отказа (см. ниже).
- **Уровень английского «угадывался».** Если в резюме и в вашем контексте о языке ничего нет,
  модель могла выбрать «C1 и выше». Теперь выбирается самый скромный вариант («A1–A2», «базовый»).

- **После закрытия приложения оставались процессы.** Ollama, которую программа запускала сама, работала
  дальше и держала модель в видеопамяти (~7,5 ГБ для qwen3:8b). Теперь при выходе модели выгружаются,
  а запущенная программой Ollama останавливается. Ollama, которую вы запустили сами, продолжает работать.
  Если при закрытии во время работы шаг завис и окно закрылось принудительно, вместе с ним закрываются
  браузер и драйвер Playwright.

### Добавлено

- **Понятный лог пагинации:** после каждой страницы программа пишет, почему идёт дальше
  («найдено 426 вакансий, страниц не меньше 9») или почему остановилась
  («это последняя страница (9 из 9)», «выдача на одной странице»).
- **Подсказка про фильтры:** если на странице фильтры отсеяли 80% вакансий и больше, программа
  предупреждает и советует проверить `[filters]`, особенно «только со словами».
- **Честные ответы без прямого опыта** в анкетах при отклике и в чатах с «Роботом-рекрутером»:
  - есть смежный опыт — нейросеть подаёт его выгодно: «С Airflow напрямую не работал, но строил
    ETL-пайплайны на Pandas и настраивал CI/CD — освою быстро»;
  - смежного опыта нет — честно пишет: «Особого опыта с этим не было, готов быстро освоить»;
  - из вариантов выбирает ближайший честный: «Нет опыта», «Базовый», «До 1 года»;
  - опыт, которого нет в резюме, по-прежнему не придумывается.
- **Отказ разрешён только по уважительным причинам:** тестовое задание, код, ссылки (GitHub, портфолио),
  документы, контакты, паспорт, оплата. На любой другой отказ программа переспрашивает нейросеть,
  а если та снова отказывается — подставляет честный ответ сама.
- **Ответы своими словами:** нейросеть пересказывает опыт из резюме, а не копирует строки дословно.
- Скриншоты приложения в README (`docs/screenshots/`), этот CHANGELOG.

### Изменено

- README переоформлен: оглавление, скриншоты, таблицы возможностей, сворачиваемые разделы.
- В `config.example.toml` поправлены комментарии к `[questions]`.

## 1.0.1-beta — 2026-10-02

### Добавлено

- **ИИ-ответы в чатах:** нейросеть отвечает на анкеты «Робота-рекрутера» по вашему резюме
  и контексту, проходит анкету до конца, читает уведомления. Живым людям, приглашениям и просьбам
  о документах не отвечает: такие чаты остаются вам.
- **Нейросети:** OpenRouter (есть бесплатные модели), DeepSeek API, Ollama на своём компьютере,
  любой OpenAI-совместимый сервис. Рекомендуемая локальная модель — `qwen3:8b`.
  Ollama запускается автоматически.
- **Анкеты при отклике с ИИ:** текст, один вариант, несколько вариантов. Технологии отмечаются
  строго по резюме, зарплата и сроки — по вашему контексту.
- **Проверка ИИ (песочница):** страница в приложении и `python ai_test.py`. Вы пишете за работодателя,
  в hh ничего не уходит. Кнопки «Что получает нейросеть» и «Тест анкеты».
- Excel: лист «Ответы в чатах», колонка «Ответы на анкету» на листе «Откликнулся».
- Резюме загружается с hh само. Телефон, почта, реклама и служебные надписи hh вырезаются.

### Исправлено

- Галочка «Только непрочитанные» сбрасывалась при открытии чата, и открывались старые прочитанные чаты.
  Теперь она проверяется перед каждым чатом.
- Сообщения «Ваши ответы отправлены работодателю» и «Анкета завершена» распознаются без нейросети,
  и программа сразу переходит к следующему чату.
- Чтение отказов ускорено: пауза 0,5–1 с на чат.
- Для Ollama и DeepSeek включён режим «строго JSON» с переспросом.

## 1.0.0-beta — 2026-10-01

Первая публичная бета.

### Добавлено

- Автоотклики по выдаче hh: по ссылке «подходящие к резюме» или по поисковому запросу
  (регион, поиск только в названии).
- Все сценарии отклика hh: окно с письмом; быстрый отклик + «Приложить письмо»; «Отклик уже просмотрен»;
  предупреждение о другом регионе (соглашается для удалёнки, отказывается при переезде);
  один вопрос о зарплате.
- Три режима сопроводительного письма: кнопка hh «Сгенерировать», готовый текст с `{vacancy}`/`{company}`,
  без письма.
- Фильтры: опыт и формат работы (фильтры hh), «только со словами», исключения по названию вакансии
  и компании.
- Чтение отказов в чатах с фильтром «Только непрочитанные».
- Excel-отчёт `responses.xlsx`: «Сводка», «Откликнулся», «Вопросы», «Пропущенные», «Не откликнулся».
  Статистика «сегодня / последний запуск / всего».
- Приложение для Windows на customtkinter, сборка `HH-Auto-Response.exe` (`build.bat`), самопроверка
  `--self-test`.
- Проверка доступа из РФ, поддержка прокси, остановка на лимите hh и после 5 ошибок подряд.

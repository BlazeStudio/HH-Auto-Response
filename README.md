# hh-auto — автоотклики на вакансии hh.ru

Скрипт проходит по вашей выдаче вакансий на hh.ru и на каждую откликается
с сопроводительным письмом, сгенерированным кнопкой «Сгенерировать» (нужна подписка hh).
Переписку с работодателями вы ведёте сами.

## Как это работает

0. **Проверка доступа из РФ.** Показывает страну внешнего IP и проверяет, что hh.ru открывается.
   Браузер работает с русской локалью и московским часовым поясом.
1. **Авторизация.** Логин и пароль скрипт не хранит и не вводит. При первом запуске откроется окно Chrome:
   войдите сами (телефон/почта → код). Сессия сохранится в папке `browser-profile/`,
   и в следующие разы входить не придётся.
2. **Резюме.** Берёт ID резюме из `resume_url` или из параметра `resume=` в ссылке поиска и проверяет,
   что такое резюме есть у вас в аккаунте. Затем в каждом окне отклика сверяет, что выбрано именно оно.
3. **Отклики.** Для каждой вакансии в выдаче:
   - «Откликнуться» → **окно с письмом** → «Сгенерировать» → ждёт текст → «Откликнуться»;
   - «Откликнуться» → **отклик ушёл сразу** («Ваш отклик отправлен работодателю») →
     «Приложить письмо» → окно «Сопроводительное письмо» → «Сгенерировать» → «Отправить»;
   - **предупреждение «вакансия в другом регионе/стране»** → скрипт соглашается и продолжает отклик,
     но отказывается, если нужен переезд: в карточке вакансии есть «переезд», «релокация»,
     «перемещение» либо у вакансии нет пометки «Можно удалённо» (настраивается в `[relocation]`);
   - открылась **страница с вопросами/тестом работодателя** → вакансия пропускается,
     скрипт возвращается назад к выдаче;
   - открылось **отдельное окно**, резюме скрыто → вакансия **пропускается**.

   Между вакансиями делается случайная пауза, затем скрипт переходит к следующей
   вакансии, а после неё — к следующей странице выдачи.

## Установка

Нужны Python 3.11+ и Google Chrome (или Edge).

```bash
pip install -r requirements.txt
```

Если нет ни Chrome, ни Edge, поставьте браузер Playwright и укажите `channel = ""` в `config.toml`:

```bash
python -m playwright install chromium
```

## Настройка

Скопируйте `config.example.toml` в `config.toml` и вставьте свою ссылку поиска в `search_url`.
Удобнее всего взять её со страницы резюме («N подходящих вакансий»): тогда в ссылке будет `resume=<ID>`.
Остальные параметры (паузы, лимиты, прокси, запасной текст письма) описаны в комментариях в файле.

## Запуск

Сначала пробный прогон: вход, проверка резюме и список вакансий без откликов:

```bash
python main.py --dry-run
```

Один настоящий отклик, чтобы убедиться, что всё работает:

```bash
python main.py --limit 1
```

Обычный запуск:

```bash
python main.py
```

| Параметр | Что делает |
|---|---|
| `--dry-run` | пройти выдачу и показать вакансии, не откликаясь |
| `--limit N` | не больше N откликов за запуск |
| `--start-page N` | начать с N-й страницы выдачи |
| `--url ССЫЛКА` | другая ссылка поиска вместо `search_url` |
| `--resume ССЫЛКА` | ссылка на резюме вместо `resume_url` |
| `--retry-skipped` | снова пробовать вакансии, пропущенные ранее (отдельные окна и т.п.) |
| `-v` | подробный лог (DEBUG) и в консоли |

Остановить можно в любой момент клавишами `Ctrl+C`: скрипт выведет итоги.

## Логи и файлы

- Консоль: каждый шаг: вакансия подтянута, какое окно открылось, письмо сгенерировано (начало текста),
  отклик отправлен, пауза, итоги запуска.
- `logs/run_*.log`: подробный лог запуска, включая полные тексты писем.
- `logs/responses.csv`: таблица всех откликов (открывается в Excel): вакансия, компания, статус, было ли письмо, причина пропуска.
- `logs/snapshots/`: скриншот и HTML страницы при каждой ошибке. Если hh поменял вёрстку, по ним можно поправить
  селекторы в `hh_auto/selectors.py`.
- `data/state.json`: память между запусками. Вакансии с отправленным откликом и пропущенные «навсегда»
  (отдельные окна, другой регион) повторно не трогаются. Вакансии, где не получилось письмо или
  случилась ошибка, будут повторены при следующем запуске.

## hh.ru и Россия

hh.ru работает только из России. Если вы за границей или сидите через VPN:
- добавьте `hh.ru` в исключения VPN (раздельное туннелирование), **или**
- укажите российский прокси в `config.toml`: `[geo] proxy = "http://user:pass@host:port"`.

Перед стартом скрипт показывает страну IP. При `require_ru_ip = true` он не запустится с нероссийского IP.
Проверку страны можно выключить: `check_ip = false`.

## Ограничения и безопасность

- У hh лимит около 200 откликов в сутки. Когда hh сообщает о лимите, скрипт останавливается.
- Капчу скрипт не обходит: если она появилась, решите её в окне браузера, и скрипт продолжит сам.
- После 5 ошибок подряд скрипт останавливается: скорее всего, hh поменял вёрстку или слетела сессия.
- Если в окне отклика выбрано не то резюме, вакансия пропускается (`skip_on_resume_mismatch`).
